# Martín Peralta

### Desarrollador centrado en Python, sistemas backend y productos prácticos

Construyo software para comprender sistemas complejos, resolver problemas reales y convertir ideas ambiciosas en prototipos funcionales. Mi objetivo es crear proyectos completos, documentados y probados, avanzando mediante resultados verificables.

## Tecnologías

- **Backend:** Python, Flask, APIs REST y SQLite
- **Web:** HTML, CSS y JavaScript
- **Ingeniería:** arquitectura de software, algoritmos, estructuras de datos y pruebas
- **Exploración:** automatización, ciberseguridad, inteligencia artificial y experiencias 3D

## Proyecto principal

Actualmente desarrollo **Iter**, un proyecto que busca ofrecer una experiencia coherente para trabajar con recursos, formatos, bibliotecas y backends.

### [Explorar la vista previa pública de Iter →](https://github.com/Martinmanhue/iter-public)

```iter
iter convert data.json to data.csv
```

La presentación pública, la arquitectura y la hoja de ruta están en `iter-public`. El código completo y las herramientas internas permanecen en un repositorio privado.

## Principios de trabajo

- Privacidad y consentimiento por diseño
- Código claro y mantenible
- Lanzamientos pequeños que funcionen de verdad
- Pruebas antes de anunciar progreso
- Aprendizaje mediante proyectos reales
